# Environment V2 — новая библиотека окружения

Независимая пересборка по `ideas/Концепт фэнтезийного хаба с воротами.png`. Первый вариант сохранён в соседней папке `Environment`.

## Открыть и посмотреть

- `EnvironmentLibraryV2.blend` — все 19 объектов, разложенные по именованным коллекциям. Это каталог моделей, а не игровая карта.
- `catalog.png` — обзор реальных рендеров; `architecture.png` — здания крупнее.
- В папке каждого объекта: редактируемый `.blend`, экспорт `.glb`, рендер `.png`.
- Открывайте `.blend` в Blender. Выберите деталь и нажмите NumPad `.` для приближения. Камера и свет скрыты в рабочем виде, но участвуют в рендере F12.
- Каждая конструктивная деталь — отдельный именованный объект: крыши, черепица, стены, ставни, кладка, декор. Материалы одноцветные, без внешних текстур.

## Состав

1. Древо путников: изогнутый ветвящийся ствол, корни, многосоставная крона, руны, подвески, флаги, каменное кольцо.
2. Ворота: две башни, угловая кладка, карнизы, клинчатая арка, крыши, флаги, фонари, ступени.
3. Ель с зубчатыми ярусами; лиственное дерево с ветвями.
4. Фонарь, секция ограды, модуль мощения, мост с опорами и перилами.
5. Три группы уступчатых скал с плоскими гранями.
6. Четыре дома: коричневая крыша, высокий красный фронтон, синий дом с крыльцом, зелёный с ящиком трав. Пропорции и фасады различаются.
7. Кузница: открытый рабочий фасад, арочная топка, труба, дровник, наковальня, молоток, инструменты, ящики и бочка.
8. Алхимик: фиолетовая крыша, боковая лавка с бутылками, котёл, зелье, ящики.
9. Смотритель: открытый павильон, тканевый навес, стойка, знак лапы и три статичные декоративные фигурки. Эти фигурки не заменяют игровые модели питомцев.
10. Торговец: полосатый тканевый навес, прилавок, ящики с ресурсами, полки с бутылками, бочка.

## Масштаб и ограничения

Авторские координаты: Z вверх, фасад в -Y. Одна единица моделирования задумана как один stud. Фактические габариты записаны в `manifest.json`; масштаб импорта нужно проверить рядом с аватаром в Studio.

Стилистика: stylized low-poly, умеренная мультяшность, матовые одноцветные материалы. Рендеры используют мягкий студийный свет для проверки формы; это не готовая настройка освещения игры.

Это приближение к PNG с восстановлением невидимых сторон. Точный перенос 1:1 не заявляется. У зданий нет оборудованных интерьеров и открывающихся дверей. Огонь, пузырьки и декоративные питомцы статичны. Анимация окружения этим запросом не реализована.

Модели ещё не импортированы в Roblox, коллизии и мобильная производительность не проверены. При интеграции объединять неподвижные детали по материалам и создавать простые отдельные коллизии; не импортировать всю библиотеку как единую игровую сцену. Дома в текущий хаб не поставлены. `MythicPets.rbxl` этой пересборкой не меняется.

## Повторная сборка

Из корня проекта в PowerShell:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/build_environment_v2.py
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/verify_environment_v2.py
& 'C:\Users\mazma\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools/catalog_environment_v2.py
```

Для одного объекта добавить к первой команде `-- --only Alchemist`. Для нескольких: `-- --only WayfarerTree,BiomeGate`.

**Повторная генерация перезапишет файлы V2. Перед ручной правкой сохраните копию `.blend` под своим именем вне генерируемых папок.**

`verification.json` создаётся только после проверки повторного открытия всех `.blend`, геометрии, рендеров и обратного импорта `.glb` с сопоставлением размеров. Эта проверка не заменяет проверку в Roblox Studio.
