# Медная руда V2

Заново построенная модель по `Концепт-лист светящейся медной руды.png` из папки ideas. Предыдущая модель сохранена в `../CopperOutcrop`.

Открывать `CopperOutcropV2.blend`. Экспорт: `CopperOutcropV2.glb`. Основной рендер: `CopperOutcropV2.png`; остальные ракурсы — `front.png`, `side.png`, `top.png`, `back.png`.

Восстановлены асимметричный силуэт, высокая левая глыба, крупная правая плоскость, угловатые медные включения и светящиеся разломы. Камни, медь и линии разломов редактируются отдельно. Материалы одноцветные, без внешних текстур. Свечение задано материалами Blender; его вид в Roblox потребует отдельной настройки.

Габариты: примерно 4.85 × 3.49 × 4.50 единицы. Z вверх, фасад -Y. 5548 треугольников. Изготовлено целое состояние залежи; состояния разрушения и эффекты удара с концепт-листа не реализованы. Это приближение к рисунку, не точное восстановление 3D-исходника.

Модель не импортирована в игровую карту. Перед интеграцией нужны проверка масштаба, объединение статичных деталей и простая коллизия. Оригинальная карта не изменялась.

Повторная генерация из корня проекта:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/build_copper_v2.py
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/verify_copper_v2.py
```

Генерация перезаписывает V2: ручные изменения сохраняйте в отдельной копии. Результаты проверки открытия, геометрии, рендеров и обратного импорта — в `verification.json`.
