## Как проверить

1. Для основного `MythicPets.rbxl` обновить скрипты через Rojo и перезапустить Play. Тестовую копию можно открыть из `download/stage4-preview.rbxl`; после пересборки уже открытая сессия не обновляется автоматически.
2. В эмуляторе нажать на синюю залежь: начинается добыча, после разрушения +10 кристаллов. Доступно нажатие на каменное основание.
3. Нажать чёрный куб: питомец атакует, куб отвечает питомцу. При 0 HP питомец отдыхает 8 секунд, затем восстанавливается; атаку нужно выбрать заново. Побеждённый куб появляется через 12 секунд. Вблизи куб наносит урон настоящему Humanoid игрока. Отзыв или выход за дистанцию прекращает атаку питомца.
4. Подойти к торговцу и нажать на него: «Привет!» → «Перейти к торговле» → «Пока нет предложений». «Уйти» закрывает окно. При отходе окно также закрывается.

Настройки: `src/shared/CombatConfig.luau`. HP питомца 30, куба 60; урон питомца 8, ответ куба питомцу 7, игроку 10. Противник персональный, неподвижный, без анимации и наград. Здоровье и действия проверяет сервер. Прогресс остаётся временным.

Исходный `MythicPets.rbxl` этой задачей не перезаписывался. Генератор тестовой копии сообщает о неизвестном свойстве Terrain.VoxelGridAssetContentMap; поэтому переносить из тестовой копии Terrain в основной плейс не следует. Для рабочей карты используется Studio и Rojo.
