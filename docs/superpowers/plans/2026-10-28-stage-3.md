# Stage 3 Implementation Plan

> Выполнение в текущей сессии по поручению пользователя перейти к этапу 3.

**Goal:** Проверяемая серверная модель профиля и безопасная граница запросов.

**Architecture:** Чистый ProfileStore получает настройки и генератор ID. Адаптер Studio подключает Players и RemoteEvent. Клиент запрашивает собственный снимок.

**Tech Stack:** Luau, Rojo 7.7.1, Lune 0.11.1 для тестов.

**Spec:** docs/stage-3-design.md

## Constraints

Прогресс временный. Карта редактируется в Studio. Баланс не утверждён. Тестовые Place2 не сохраняются в Git. Между чтением и записью профиля нет yield.

## Review focus

Чужие ID, повторная экипировка, переполнение команды, повреждённый запрос и изменение клиентской копии должны проверяться тестами.
