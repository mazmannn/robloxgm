# Проверка этапа 3 в Roblox Studio

Дата: 28.10.2026, 12:36–12:43, Asia/Novosibirsk.
Плейс: MythicPets.rbxl. Проверка выполнена через управление приложением Studio, код вводился в клиентский Command Bar. Исходные файлы и карта во время проверки не менялись.

## Одиночная сессия

После остановки старой сессии и нового Play выполнен сценарий с assert и ожиданием реального ответа RemoteEvent:

- GetState возвращает MemoryOnly и одного стартового питомца.
- UnequipPet оставляет пустую команду и сохраняет питомца в коллекции.
- EquipPet возвращает питомца в команду.
- Повторный EquipPet не дублирует питомца.
- GetState с лишним полем userId отклоняется как InvalidRequest.
- EquipPet с неизвестным ID отклоняется как PetNotOwned.
- RecallTeam возвращает Idle.
- После отклонённых запросов обычный GetState продолжает работать; кристаллы равны нулю.

В Output и журнале получен маркер QA_PASS SINGLE_CLIENT_ALL.

## Сервер с двумя клиентами

Запущен отдельный локальный сервер через Test → Start Test Session → Server and Clients, затем добавлены два клиента.

- Player1 и Player2 одновременно присутствуют в мире и видят персонажей друг друга.
- У игроков разные GUID питомцев, в снимке Player2 нет питомца Player1.
- Player1 снял своего питомца: команда 0. У Player2 команда осталась 1.
- Player2 отправил EquipPet и UnequipPet с реальным GUID питомца Player1: оба отклонены как PetNotOwned.
- Попытка Player2 указать чужой userId отклонена как InvalidRequest.
- У Player1 счётчик полученных Response не изменился от запросов Player2: ответы адресуются только отправителю.
- После запросов Player2 у Player1 команда по-прежнему 0. Повторная экипировка собственного питомца успешна.

Маркеры: QA_PASS PLAYER2_ALL, QA_PASS RESPONSE_ISOLATION, QA_PASS PLAYER1_STILL_ZERO, QA_PASS TWO_CLIENTS_ALL.

## Перезапуск

Многопользовательская сессия остановлена через End Session. В основном плейсе снова запущен Play. У того же пользователя новый GUID стартового питомца, команда 1, кристаллы 0, storageMode MemoryOnly. Маркер QA_PASS NEW_SESSION_RESET. Затем тест остановлен, Studio оставлена в режиме редактирования.

Это проверка нового сервера/сессии. Перезаход на тот же работающий сервер отдельно не выполнялся.
