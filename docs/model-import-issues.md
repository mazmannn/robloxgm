# Замечания по импорту моделей

## 2026-10-29 — цвета не переносятся в Roblox Studio

Пользователь сообщил: импортированная модель отображается в Roblox Studio без цветов. Зафиксированная проблема текущего процесса переноса наших моделей из Blender: цвета материалов не импортируются корректно.

Статус: отложено по прямому указанию пользователя. Сейчас не диагностировать и не исправлять. Причина пока не установлена; распространение проблемы на каждый экспортированный файл отдельно не проверено.

При возвращении к полноценному переносу моделей проверить передачу цветов и материалов на одном образце до массового импорта. Наличие цветов в Blender и проверка обратного импорта GLB в Blender не подтверждают их корректное отображение в Roblox Studio.
